# Sicherheit

## Eine Lücke melden

Bitte melde Sicherheitslücken nicht öffentlich als Issue. Nutze stattdessen die private Meldung über den Tab **Security → Report a vulnerability** auf GitHub. Dort bleibt die Meldung nur für den Betreiber sichtbar.

Bitte beschreibe, was passiert, welche Version betroffen ist und wie man den Fehler reproduziert.

## Unterstützte Versionen

Es wird jeweils nur die neueste Version unterstützt. Ältere Versionen erhalten keine Korrekturen.

## Was die App nicht speichert

Das Passwort für mytischtennis.de wird nie gespeichert. Die Sitzungs-Cookies liegen verschlüsselt auf dem Gerät, der Schlüssel liegt im Android Keystore.
